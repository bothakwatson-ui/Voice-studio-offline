# Voice Studio Offline

Voice Studio Offline is an Android application for recording voices and creating music without an internet connection.

## Main Features

1. Record voice and singing.
2. Play piano and guitar sounds.
3. Create drum beats.
4. Mix voice and musical instruments.
5. Adjust volume and sound effects.
6. Play recorded music.
7. Save completed songs on the phone.
8. Work completely offline.

## Project Goal

To develop an easy-to-use Android music studio for recording, editing, mixing and producing songs.

## Platform

Android smartphones.
